Debounce vs Throttle

Debouncing (Search Input) Triggers: 0

Debounce waits for a delay (e.g. 500ms) of silence/inactivity before execution. Useful for Search inputs.

Throttling (Button Clicking) Triggers: 0

Throttle runs the function immediately, then blocks execution for a lock delay (e.g. 1000ms). Useful for clicks/resizes.

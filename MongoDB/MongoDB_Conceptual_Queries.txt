--------------------------------------------------------------------------------
ESSENTIAL MONGODB AGGREGATION QUERIES (BANGALORE HITS)
--------------------------------------------------------------------------------

1. E-commerce: Group orders by product category and calculate average price:
   db.products.aggregate([
     { $group: { _id: "$category", avgPrice: { $avg: "$price" } } }
   ])

2. Joint Search: Join Orders collection with Users collection (borrowing references):
   db.orders.aggregate([
     {
       $lookup: {
         from: "users",
         localField: "userId",
         foreignField: "_id",
         as: "userDetails"
       }
     },
     { $unwind: "$userDetails" }
   ])

3. Filtering and Projection: Find active users and select only name and email:
   db.users.aggregate([
     { $match: { status: "active" } },
     { $project: { _id: 0, name: 1, email: 1 } }
   ])

4. Unwinding Arrays: Flatten an array of tag elements to aggregate tags counts:
   db.posts.aggregate([
     { $unwind: "$tags" },
     { $group: { _id: "$tags", count: { $sum: 1 } } },
     { $sort: { count: -1 } }
   ])

5. Dynamic Pagination: Perform limit/skip aggregation:
   db.logs.aggregate([
     { $match: { level: "error" } },
     { $sort: { timestamp: -1 } },
     { $skip: 10 },
     { $limit: 10 }
   ])

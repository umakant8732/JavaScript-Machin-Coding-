1. COMPUTER MEMORY (RAM) BASICS: THE POSTBOX ANALOGY
--------------------------------------------------------------------------------
Think of RAM as a very long row of post-boxes, each with a unique number (index) 
starting from 0, 1, 2, 3...

- ARRAY STORAGE:
  When you declare an array like:
  let arr = [10, 20, 30];
  
  The computer reserves consecutive post-boxes in RAM:
  - Post-box [0] contains 10
  - Post-box [1] contains 20
  - Post-box [2] contains 30

- INSTANT ACCESS (O(1)):
  If you ask for `arr[2]`, the computer does NOT scan index 0 and 1.
  It instantly (in 1 step) jumps to index 2 and retrieves 30.
  This instant, single-step lookup is called O(1) Constant Time.


2. TIME & SPACE COMPLEXITY (BIG O)
--------------------------------------------------------------------------------
Big O Notation tells us how the running time or memory usage of our code grows 
as the input size (N) grows.

A. O(1) - Constant Complexity (Instant Speed)
   - The code always takes 1 step to run, no matter how big the input is.
   - Example:
     function getFirstElement(arr) {
         return arr[0]; // Takes exactly 1 step
     }

B. O(N) - Linear Complexity (Directly proportional to input size)
   - If the input array has N elements, the loop runs N times.
   - Example:
     function printElements(arr) {
         for (let i = 0; i < arr.length; i++) { // Runs N times
             console.log(arr[i]);
         }
     }

C. O(N^2) - Quadratic Complexity (Nested Loops)
   - A loop inside a loop. If input has N elements, it runs N * N times.
   - Example:
     function printPairs(arr) {
         for (let i = 0; i < arr.length; i++) {       // Runs N times
             for (let j = 0; j < arr.length; j++) {   // Runs N times for each i
                 console.log(arr[i], arr[j]);
             }
         }
     }


3. QUESTION 1: LINEAR SEARCH THEORY
--------------------------------------------------------------------------------
- PROBLEM:
  Given an array `arr` and a `target` value, find if `target` exists in `arr`.
  If yes, return its index. If no, return -1.

- CONCEPT:
  Start from index 0 and compare each element with the target one by one:
  Array: [5, 8, 2, 11, 15], Target: 11
  
  Step 1: Check index 0 -> Is 5 == 11? (No)
  Step 2: Check index 1 -> Is 8 == 11? (No)
  Step 3: Check index 2 -> Is 2 == 11? (No)
  Step 4: Check index 3 -> Is 11 == 11? (Yes! Return index 3)

- COMPLEXITY:
  - Time Complexity: O(N)
    In the worst case (if the target is at the very end or not in the array), 
    we have to check all N elements one by one.
  
  - Space Complexity: O(1)
    We are not using any extra arrays or memory to search; we only use a 
    single loop counter variable `i` which takes constant space.

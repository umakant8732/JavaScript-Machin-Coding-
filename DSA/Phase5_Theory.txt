1. PREREQUISITE THEORY: SLIDING WINDOW BASICS
--------------------------------------------------------------------------------

A. SUBARRAY VS SUBSEQUENCE:
   - SUBARRAY: A contiguous (continuous) part of an array.
     For [1, 2, 3, 4], [2, 3] is a subarray, but [1, 3] is NOT.
   - SUBSEQUENCE: Elements in order, but not necessarily contiguous.
     For [1, 2, 3, 4], [1, 3] is a subsequence.

B. WHAT IS SLIDING WINDOW?
   - Instead of recalculating sums/substrings of size K from scratch (which takes O(N*K) 
     using nested loops), we maintain a "window" of elements.
   - When the window moves right:
     - We add the new element entering the window.
     - We remove the old element leaving the window.
     - This updates state in O(1) time, bringing total time down to O(N).


2. TWO TYPES OF SLIDING WINDOW TEMPLATES
--------------------------------------------------------------------------------

A. FIXED SIZE WINDOW TEMPLATE (Size K):
```javascript
let currentSum = 0;
// 1. Calculate sum of first K elements
for (let i = 0; i < K; i++) currentSum += arr[i];
let maxSum = currentSum;

// 2. Slide the window from index K to N-1
for (let i = K; i < arr.length; i++) {
    currentSum += arr[i] - arr[i - K]; // Add new, subtract old
    maxSum = Math.max(maxSum, currentSum);
}
```

B. VARIABLE SIZE WINDOW TEMPLATE (Find Max/Min window meeting condition):
```javascript
let left = 0;
let maxLength = 0;

for (let right = 0; right < arr.length; right++) {
    // 1. Add arr[right] to window state
    
    // 2. While state is invalid, shrink window from left
    while (conditionIsInvalid) {
        // Remove arr[left] from state
        left++;
    }
    
    // 3. Update result
    maxLength = Math.max(maxLength, right - left + 1);
}
```


3. CORE QUESTIONS EXPLAINED (CONCEPT & COMPLEXITY)
--------------------------------------------------------------------------------

Q26: Max Sum Subarray of Size K
- Concept: Use the Fixed Size Window template. Tally initial sum, slide the window 
  forward, updating maximum sum at each step.
- Time: O(N), Space: O(1).

Q27: Longest Substring Without Repeating Characters (Extremely Common)
- Concept: Use the Variable Size Window template.
  - Keep a `Set` to store characters in current window.
  - Iterate `right` pointer. If `str[right]` is already in Set, shrink window by doing 
    `Set.delete(str[left])` and `left++` until duplicate is removed.
  - Add `str[right]` to Set, and compute `maxLength = max(maxLength, right - left + 1)`.
- Time: O(N), Space: O(U) where U is unique character set (max 256).

Q28: Subarray Sum Equals K
- Concept: We need to find how many subarrays sum up to K (handles negative numbers).
  - Use **Prefix Sum + HashMap**.
  - Keep a running `sum`. If `sum === K`, increment count.
  - If `sum - K` exists in our map (which stores how many times prefix sums have occurred), 
    add its count to our answer.
  - Store `sum` in map.
- Time: O(N), Space: O(N).

Q29: Longest Subarray with Sum K
- Concept: If array has only positive numbers, we use two pointers sliding window:
  - Keep a running `currentSum`.
  - Iterate `right` pointer. Add `arr[right]` to sum.
  - If `currentSum > K`, do `currentSum -= arr[left]` and `left++` until sum <= K.
  - If `currentSum === K`, update max length.
- Time: O(N), Space: O(1).

================================================================================
DSA LEARNING ROADMAP FOR MERN STACK DEVELOPERS (BANGALORE VETTED - 41 QUESTIONS)
================================================================================

A curated, pattern-based study plan specifically designed to transition you from 
absolute basics (zero DSA background) to cracking technical coding rounds at 
Bangalore startups (6-8 LPA).

HOW WE STUDY EACH PATTERN:
1. Prerequisite Theory First (Memory basics, pointers, mutability, Object hashing)
2. Big O Complexity Analysis (Counting loops visually)
3. Pseudocode/Logic building
4. JavaScript implementation and dry run

================================================================================
PROGRESS TRACKER
================================================================================

[ ] PHASE 0: RAM MEMORY & BIG O BASICS
--------------------------------------------------------------------------------
Goal: Understand memory layouts and how to measure loop complexity visually.
Theory: RAM postbox analogy, O(1) constant vs O(N) linear vs O(N^2) nested loops.
- [ ] Q01: Linear Search (Teaches O(N) Time Complexity)

[ ] PHASE 1: BASIC ARRAYS & TWO POINTERS PATTERN
--------------------------------------------------------------------------------
Goal: Master index pointers walking inward/outward.
Theory: Mutability vs Immutability, Element Swapping, Two Pointers template.
- [ ] Q02: Reverse String / Array (In-place Swap + Two Pointers)
- [ ] **Q03: Check Palindrome** (Symmetry using Two Pointers)
- [ ] **Q04: Move Zeroes** (Write Pointer dynamic in-place shifting)
- [ ] **Q05: Separate Even and Odd Numbers** (In-place Array Partitioning)
- [ ] **Q06: Remove Duplicates from Sorted Array** (Read/Write Pointer mapping)
- [ ] **Q07: Check if String is Subsequence of Another** (Two pointer scan)
- [ ] **Q08: Squares of a Sorted Array** (Opposite ends pointers meeting)
- [ ] **Q09: Valid Palindrome II** (Two pointers with 1-character deletion fallback)
- [ ] **Q10: Container With Most Water** (Inward movement based on height logic)

[ ] PHASE 2: HASH MAP & HASH SET PATTERN
--------------------------------------------------------------------------------
Goal: Master O(1) fast key-value index lookups.
Theory: Objects as Hash Maps, Frequency Counting Pattern.
- [ ] **Q11: Contains Duplicate** (Set lookup helper)
- [ ] **Q12: Character Frequency** (Object-based key counting)
- [ ] **Q13: First Repeating Character** (Set element check)
- [ ] **Q14: First Non-Repeating Character** (Two-pass frequency lookup)
- [ ] **Q15: Valid Anagram** (Checking character occurrence counts matches)
- [ ] **Q16: Two Sum (Unsorted)** (HashMap target complement lookup in O(N))
- [ ] **Q17: Intersection of Two Arrays** (Set comparison and matching)
- [ ] **Q18: Find All Duplicates in Array** (Index sign swap tracking or Hash Map)

[ ] PHASE 3: JS LOGIC, POLYFILLS & CACHING (CORE JS INTERVIEWS)
--------------------------------------------------------------------------------
Goal: Understand JS runtime engine, timing scopes, prototypes, and closures.
Theory: Prototypes, closures, timing loops, and caching logic.
- [ ] **Q19: Array Polyfills** (Implementing map, filter, and reduce from scratch)
- [ ] **Q20: Debounce & Throttle** (Closures and asynchronous timing wrappers)
- [ ] **Q21: Memoization / Caching Function** (Custom memoized cache objects)

[ ] PHASE 4: RECURSION & NESTED OBJECTS (MERN SPECIAL)
--------------------------------------------------------------------------------
Goal: Master recursive call-stacks and nested tree/JSON structures (DOM equivalents).
Theory: Call stack frames, base cases, DFS tree traversal.
- [ ] **Q22: Flatten a Nested Array** (Recursive sub-array unpacking)
- [ ] **Q23: Deep Clone Object** (Recursive value copying)
- [ ] **Q24: Flatten a Nested Object** (Deep JSON to dot-notation keys converter)
- [ ] **Q25: N-ary Category/Folder Search** (DFS traversal on folders/reply threads)

[ ] PHASE 5: SLIDING WINDOW PATTERN
--------------------------------------------------------------------------------
Goal: Optimize nested subarrays checking (O(N^2) to O(N)) using boundary window shifts.
Theory: Contiguous subarrays, fixed vs variable window contraction.
- [ ] **Q26: Max Sum Subarray of Size K** (Fixed-size sliding window)
- [ ] **Q27: Longest Substring Without Repeating Characters** (Variable-size sliding window)
- [ ] **Q28: Subarray Sum Equals K** (Prefix Sum + HashMap lookup)
- [ ] **Q29: Longest Subarray with Sum K** (Dynamic window expansion/contraction)

[ ] PHASE 6: STACKS & QUEUES (BUFFERS)
--------------------------------------------------------------------------------
Goal: Process data segments sequentially using LIFO/FIFO order.
Theory: LIFO stack buffers vs FIFO queue schedulers.
- [ ] **Q30: Valid Parentheses** (LIFO bracket parsing)
- [ ] **Q31: Min Stack** (Auxiliary stack O(1) minimum tracking)
- [ ] **Q32: Simplify Path** (Unix folder backtrack resolver using stack)
- [ ] **Q33: Next Greater Element** (Monotonic stack scans)
- [ ] **Q34: Task Runner with Concurrency Limit** (Queue-based async scheduler)

[ ] PHASE 7: SEARCHING, SORTING & LINKED LISTS
--------------------------------------------------------------------------------
Goal: Custom sorting, logarithmic splits, and linked reference manipulation.
Theory: Custom comparators, halving search boundaries, next pointer references.
- [ ] **Q35: Binary Search** (Logarithmic O(log N) search)
- [ ] **Q36: Bubble Sort** (Adjacent swaps visualization)
- [ ] **Q37: Sort Array of Objects** (Custom comparators for sorting API data)
- [ ] **Q38: Search in 2D Matrix** (Coordinate mapping binary search)
- [ ] **Q39: Reverse a Linked List** (Reference pointer updates)
- [ ] **Q40: Detect Loop / Find Middle** (Fast & Slow pointers check)
- [ ] **Q41: Remove N-th Node From End** (Offset pointers deletion)

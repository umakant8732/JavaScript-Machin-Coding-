1. PREREQUISITE THEORY: HOW JAVASCRIPT OBJECTS ACT AS HASH MAPS
--------------------------------------------------------------------------------

A. HASH MAP CONCEPT (O(1) Lookup):
   - In traditional arrays, searching for an element takes O(N) time because you must 
     scan element by element (Linear Search).
   - A Hash Map maps a key directly to a value, allowing insert, delete, and lookup 
     operations in O(1) Constant Time.
   - In JavaScript, standard Objects `{}` and the native `Map` object act as Hash Maps.
     Example:
     let userMap = {};
     userMap["umakant"] = "MERN Developer"; // O(1) insertion
     console.log(userMap["umakant"]);        // O(1) lookup: returns "MERN Developer"

B. THE HASH SET CONCEPT:
   - A Set is a collection that stores UNIQUE values.
   - In JavaScript, we use native `Set`:
     let uniqueSet = new Set();
     uniqueSet.add(5);
     uniqueSet.add(5); // Duplicate ignored, Set only contains [5]
     console.log(uniqueSet.has(5)); // O(1) lookup: returns true


2. THE FREQUENCY COUNTING PATTERN (THE TEMPLATE)
--------------------------------------------------------------------------------
This pattern counts how many times each character or number occurs in a string/array.

```javascript
let counts = {};
for (let num of arr) {
    // If num is already in counts, increment it. Otherwise, set it to 1.
    counts[num] = (counts[num] || 0) + 1;
}
```


3. CORE QUESTIONS EXPLAINED (CONCEPT & COMPLEXITY)
--------------------------------------------------------------------------------

Q11: Contains Duplicate
- Concept: Loop through the array. Put visited elements into a `Set`. If the current 
  element is already present in the `Set`, return true immediately (duplicate found).
- Time: O(N), Space: O(N) (to store visited elements in the Set).

Q12: Character Frequency
- Concept: Build a frequency map object by looping through the string. Store each 
  character as key and its count as value.
- Time: O(N), Space: O(U) where U is the count of unique characters in the string.

Q13: First Repeating Character
- Concept: Keep a `Set` of visited characters. While iterating through the string, 
  return the first character that already exists in the `Set`.
- Time: O(N), Space: O(N).

Q14: First Non-Repeating Character
- Concept: Two-pass lookup:
  - First Pass: Build the frequency map of the string (counts of characters).
  - Second Pass: Loop through the string again. The first character with a count of 1 
    in our frequency map is the answer. If none, return -1.
- Time: O(N), Space: O(1) (since unique character count maxes out at 26 lowercase letters).

Q15: Valid Anagram
- Concept: If lengths differ, return false. Build a frequency count of string `s` in an 
  object. Loop through string `t` and decrement counts. If count becomes less than 0 
  or key doesn't exist, return false.
- Time: O(N), Space: O(1).

Q16: Two Sum (Unsorted)
- Concept: Instead of O(N^2) nested loops, use a map. Loop through the array. At each 
  element, calculate the complement: `comp = target - current`. If `comp` exists in 
  our map, return `[map[comp], currentIdx]`. Otherwise, store current element's 
  value and its index in the map: `map[current] = index`.
- Time: O(N), Space: O(N).

Q17: Intersection of Two Arrays
- Concept: Put elements of `arr1` in a `Set`. Loop through `arr2`. If an element exists 
  in the Set, add it to our result array and remove it from the Set (to avoid duplicate 
  intersection matching).
- Time: O(N + M), Space: O(N) (to store arr1 elements).

Q18: Find All Duplicates in Array
- Concept: 
  - Standard Approach: Build a frequency count map and collect keys with value > 1.
  - In-Place Marking: Loop through array. For each element, go to index `abs(arr[i]) - 1`. 
    If value at that index is negative, then `abs(arr[i])` is a duplicate (visited twice). 
    Otherwise, negate the value at that index to mark it as visited.
- Time: O(N), Space: O(1) (for in-place marking).

1. PREREQUISITE THEORY: PROTOTYPES, CLOSURES, AND MEMOIZATION
--------------------------------------------------------------------------------

A. PROTOTYPES:
   - In JS, methods like `.map()`, `.filter()` belong to `Array.prototype`. 
   - By adding a method to `Array.prototype`, we make it available to all array instances.
   - Inside prototype functions, the keyword `this` refers to the array itself.

B. CLOSURES:
   - A closure is a function that remembers and has access to its outer lexical scope 
     even after the outer function has finished executing.
   - This is crucial for maintaining internal timers (in debounce/throttle) or caches 
     (in memoize) without polluting the global scope.

C. MEMOIZATION:
   - Storing the results of expensive function calls and returning the cached result 
     when the same inputs occur again.

Q19: Array Polyfills (map, filter, reduce)

- Polyfill of Array.prototype.map:
  - Concept: Returns a new array. Loops through the array (`this`) and executes the 
    callback function on each element. Pushes the returned callback value to the new array.
  - Implementation:
    ```javascript
    Array.prototype.myMap = function(callback) {
        let result = [];
        for (let i = 0; i < this.length; i++) {
            result.push(callback(this[i], i, this));
        }
        return result;
    };
    ```

- Polyfill of Array.prototype.filter:
  - Concept: Returns a new array containing elements that pass the callback condition 
    (returns true).
  - Implementation:
    ```javascript
    Array.prototype.myFilter = function(callback) {
        let result = [];
        for (let i = 0; i < this.length; i++) {
            if (callback(this[i], i, this)) {
                result.push(this[i]);
            }
        }
        return result;
    };
    ```

- Polyfill of Array.prototype.reduce:
  - Concept: Accumulates values into a single result. If an initial value is provided, 
    accumulator starts with it, and index starts at 0. Otherwise, accumulator starts 
    at array element index 0, and loop index starts at 1.
  - Implementation:
    ```javascript
    Array.prototype.myReduce = function(callback, initialValue) {
        let accumulator = initialValue !== undefined ? initialValue : this[0];
        let startIdx = initialValue !== undefined ? 0 : 1;
        for (let i = startIdx; i < this.length; i++) {
            accumulator = callback(accumulator, this[i], i, this);
        }
        return accumulator;
    };
    ```

Q20: Debounce & Throttle

- Debounce:
  - Concept: Delays executing a function until a certain time (delay) has passed since 
    the last trigger. Useful for search input autocompletes.
  - Analogy: Elevators do not close their door immediately. They wait 10 seconds after 
    the LAST person gets in.
  - Implementation:
    ```javascript
    function debounce(func, delay) {
        let timer;
        return function(...args) {
            clearTimeout(timer);
            timer = setTimeout(() => func.apply(this, args), delay);
        };
    }
    ```

- Throttle:
  - Concept: Limits execution of a function to once every interval (delay). Useful for 
    scroll handlers or resize listeners.
  - Analogy: A green signal lets traffic pass once every 2 minutes, regardless of how 
    many cars press the horn.
  - Implementation:
    ```javascript
    function throttle(func, delay) {
        let lastCall = 0;
        return function(...args) {
            let now = Date.now();
            if (now - lastCall >= delay) {
                lastCall = now;
                func.apply(this, args);
            }
        };
    }
    ```

Q21: Memoization / Caching Function
- Concept: Return a function that stores execution outputs inside a private object 
  (cache). Use function arguments (serialized as a JSON string key) to check for cache 
  hits.
- Implementation:
  ```javascript
  function memoize(func) {
      const cache = {};
      return function(...args) {
          const key = JSON.stringify(args);
          if (key in cache) {
              return cache[key]; // Cache hit
          }
          const result = func.apply(this, args);
          cache[key] = result; // Cache store
          return result;
      };
  }
  ```

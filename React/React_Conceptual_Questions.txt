================================================================================
REACT.JS CONCEPTUAL INTERVIEW QUESTIONS (EASY TO MEDIUM - BANGALORE HITS)
================================================================================

This document contains highly curated React conceptual questions commonly asked in
MERN stack developer interviews by top Bangalore tech companies (Swiggy, Razorpay, etc.).

--------------------------------------------------------------------------------
1. Virtual DOM & Reconciliation (Fiber Engine)
   - Core: How does the reconciliation algorithm work? Explain the difference between React 15 stack vs React 16+ Fiber.
   - Key terms: Diffing algorithm, keys in lists, rendering phase vs commit phase.

2. React Lifecycle & useEffect Hook
   - Core: How does useEffect replace componentDidMount, componentDidUpdate, and componentWillUnmount?
   - Practical: Cleaning up subscriptions, event listeners, and timers in useEffect.

3. Strict Mode Double Render
   - Core: Why does React run effects and renders twice in development mode?
   - Practical: Ensuring component purity and identifying side effects.

4. React Hooks Under the Hood
   - Core: How does React track hook states (Linked List)?
   - Rules: Why must hook declarations follow a strict order and not be placed inside loops or conditions?

5. Performance Optimization: useMemo vs useCallback vs React.memo
   - Core: What is the exact difference? When does memoization cause more overhead than benefits?
   - Practical: Avoiding reference identity re-renders for children components.

6. State Management: Context API vs Redux / Zustand
   - Core: When to use Context API vs standard external state managers?
   - Performance: How does Context trigger re-renders on all consumers? How do you prevent it (split contexts, selectors)?

7. React Concurrent Features: useTransition & useDeferredValue
   - Core: What is transition state? How does React split urgent vs non-urgent updates?
   - Practical: Optimizing CPU-heavy filter rendering or dynamic slider updates.

8. Custom Hooks Design Pattern
   - Core: Why write custom hooks? How do they share logic but not state?
   - Practical: Writing clean interfaces for local state syncing or window resize events.

9. Error Boundaries
   - Core: How do you catch runtime exceptions in the component tree?
   - Constraint: Why must Error Boundaries be class components (componentDidCatch)?

10. React Server Components (RSC) vs Client Components
    - Core: What are RSCs? How do they differ from Server-Side Rendering (SSR)?
    - Benefits: Shorter bundle sizes, zero-client-dependency fetching, security benefits.
